## Sobre o projeto

O **Escopo Fácil** é uma plataforma web de gerenciamento de projetos que centraliza tarefas, prazos e colaboração em equipe. Foi desenvolvido como projeto acadêmico no curso de **Tecnologia em Sistemas para Internet do Centro Universitário Senac**.

A aplicação reúne um site institucional, um sistema de organização com quadro Kanban e um painel administrativo. O objetivo é facilitar o acompanhamento das entregas e tornar visível o andamento do trabalho de cada equipe.

## Principais funcionalidades

- **Projetos e tarefas:** quadro Kanban, checklists, busca, prioridades e prazos.
- **Colaboração:** gerenciamento de membros e permissões por função.
- **Acompanhamento:** dashboard com gráficos, relatórios e histórico de atividades.
- **Contas:** cadastro, confirmação por e-mail, recuperação de senha e personalização de perfil.
- **Administração:** gestão de usuários, planos e assinaturas, com buscas e indicadores.
- **Planos:** Free, Escopo Pro e Equipe, com sete dias de acesso aos recursos avançados para novas contas Free.
- **Experiência visual:** interface responsiva, temas claro e escuro e notificações de itens não visualizados.
- **Acesso pelo celular:** navegação adaptada e opção de adicionar o app à tela inicial com o ícone do projeto, conforme o navegador.

O projeto é acadêmico: o checkout PIX é demonstrativo, sem cobranças reais. O uso do sistema e do atalho requer conexão com a internet.

## Tecnologias

| Área | Tecnologias principais |
| --- | --- |
| Interface | HTML, CSS, JavaScript, Blade, React e Motion |
| Backend | PHP e Laravel 12 |
| Gráficos | Chart.js |
| Banco de dados | PostgreSQL na hospedagem e SQLite no desenvolvimento |
| Testes | PHPUnit e testes JavaScript com Node.js |
| Build e entrega | Vite, Docker, GitHub Actions, Vercel e Neon |
